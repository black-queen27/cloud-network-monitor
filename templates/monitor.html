Computer Networks Concept: How Ping Works

1. ICMP Echo Request

The client sends an ICMP Echo Request packet (Type 8) encapsulated inside an IPv4 datagram to the destination host's IP address.

2. ICMP Echo Reply

If the target is alive and reachable, its TCP/IP networking stack responds with an ICMP Echo Reply packet (Type 0).

3. Round Trip Time (RTT)

The time difference between transmitting the request packet and receiving the reply is measured in milliseconds as latency (RTT).

4. Packet Loss

If reply packets do not return before the timeout threshold, packet loss occurs, signaling network congestion or firewall blockage.
